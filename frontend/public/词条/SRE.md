# 风格化渲染方程（SRE）  
  
## 概念解释  
  
风格化渲染方程（Stylized Rendering Equation, SRE）是经典渲染方程的泛化形式，旨在以统一框架同时描述基于物理的渲染（PBR）的真实光传输与非真实感渲染（[[NPR]]）的风格化效果。核心机制是在每个反弹点对反射辐射度递归应用非线性函数，从而实现风格化与物理光传输的无缝混合。  
  
经典[[光追#^814ae5 |渲染方程]]中光传输算子为线性，可将递归积分展开为路径空间中的高维定积分序列，每条路径独立采样，计算时间随样本数线性增长。SRE引入非线性算子后，该展开不再成立。其递归形式可表示为：  
  
$$L_o(\mathbf{x}, \omega_o) = L_e(\mathbf{x}, \omega_o) + f\left(\int_{\Omega} \rho(\mathbf{x}, \omega_i, \omega_o) L_i(\mathbf{x}, \omega_i) \cos\theta_i \, d\omega_i\right)$$  
  
其中 $f$ 为非线性风格化函数，在每个反弹点递归作用于反射辐射度积分结果。$L_e$ 为自发光项，$\rho$ 为双向反射分布函数（BRDF），$L_i$ 为入射辐射度，$\Omega$ 为半球方向域。  
  
由于非线性函数与积分运算不可交换，即：  
  
$$f\left(\mathbb{E}[X]\right) \neq \mathbb{E}[f(X)]$$  
  
直接应用蒙特卡洛路径追踪对噪声辐射度估计施加非线性函数会产生有偏结果。  
  
SRE将经典光传输与特定NPR风格化统一建模为期望的函数，将渲染方程的递归积分推广为期望的递归函数。  
  
## 核心挑战  
  
SRE的朴素估计器在每个风格化表面处需要分支，产生指数级的计算与存储开销。设路径长度为 $n$，每个反弹有两种选择（应用或不应用风格化），则路径数量为 $O(2^n)$。这一指数复杂度是SRE实际部署的主要障碍。  
  
## 参考实现示例  
  
以下为SRE朴素分支估计器的递归伪代码实现：  
  
```python  
def sre_radiance(x, wo, depth, max_depth):  
    # 自发光项  
    L = Le(x, wo)  
    
    if depth >= max_depth:  
        return L  
    
    # 采样入射方向  
    wi, pdf = sample_hemisphere(x)  
    
    # 计算反射辐射度（物理部分）  
    Li = sre_radiance(x_next(x, wi), -wi, depth + 1, max_depth)  
    reflectance = rho(x, wi, wo) * Li * cos(theta) / pdf  
    
    # 应用非线性风格化函数  
    stylized = f(reflectance)  
    
    # 分支：同时保留物理路径和风格化路径  
    L_physical = L + reflectance  
    L_stylized = L + stylized  
    
    # 实际渲染中需维护所有分支路径  
    return L_physical, L_stylized  
```  
  
实际求解SRE的实用方法包括：  
  
**非线性路径滤波（NL-PF）** ：缓存中间反弹处的辐射度评估值，将分支估计器的指数采样成本降为多项式成本。核心思想是对路径空间中的中间节点复用辐射度计算结果，避免每条分支路径独立重复计算。  
  
**非线性辐射度缓存（NL-NRC）** ：使用紧凑神经网络存储辐射度场。网络学习应用非线性函数之前的出射辐射度，即使只能访问有偏梯度，网络仍能收敛至正确解。NL-NRC的采样时间复杂度与非分支路径追踪相同（$O(n)$），可处理高反弹次数和递归风格化。  
  
NL-PF的时间复杂度为 $O(n^k)$（$k$ 为风格化配置数），空间复杂度为 $O(n^k)$；NL-NRC的时间复杂度为 $O(n)$，空间复杂度由神经网络参数量决定。  
  
## 应用场景  
  
1. **风格化与物理渲染融合**：在单一渲染框架中同时生成物理准确的光照和卡通着色、色彩映射等NPR效果，实现两者平滑过渡。  
  
2. **非真实感渲染的路径空间统一**：将交叉阴影、特征线等传统图像空间风格化操作提升至路径空间，使风格化与光传输自然交互。  
  
3. **探索性视觉风格生成**：通过设计任意非线性函数 $f$，生成传统渲染公式难以描述的视觉效果。  
  
## 常见误区  
  
**误区一：SRE是在渲染完成后对图像施加后期滤镜。** SRE的非线性函数在光传输的每个反弹点递归应用，风格化效果与光照物理过程深度耦合，而非独立的图像后处理阶段。这一区别决定了SRE能够产生光路与风格化相互影响的全局效果。  
  
**误区二：SRE可直接使用标准路径追踪器求解。** 标准路径追踪依赖光传输算子的线性性质展开路径积分。SRE的非线性算子破坏了这一性质，朴素应用路径追踪会产生有偏估计。求解SRE需要专门的非线性蒙特卡洛方法。
