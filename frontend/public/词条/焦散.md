## 概念解释  
  
焦散（Caustics）是光线经光滑曲面反射或折射后在漫反射表面形成的聚光现象。在计算机图形学中，焦散定义为任何从光源经过镜面（Specular）反射或折射、到漫反射（Diffuse）表面、再到摄影机的光照贡献。  
  
焦散的产生路径为：光源 → 镜面反射/折射（一次或多次）→ 漫反射表面 → 摄影机。其中，镜面表面称为焦散投射物体，漫反射表面称为焦散接收物体。  
  
标准蒙特卡洛路径追踪难以有效渲染焦散，原因在于从摄影机出发的射线需要以极低概率命中一条经过多次镜面反射后连接光源的路径。光子映射通过从光源发射光子并在漫反射表面存储光子信息来解决此问题。  
  
## 光子映射算法  
  
光子映射是一种两阶段全局光照算法。  
  
### 阶段一：光子贴图创建  
  
从光源向场景发射光子。光子与几何表面相交时，将相交位置、入射方向及功率存入光子贴图（Photon Map）。通常创建两类光子贴图：全局光子贴图和焦散光子贴图。焦散光子贴图仅对可产生焦散的物体（透明物体和镜面物体）发射光子。  
  
光子发射的终止条件包括：光子被吸收、逸出场景、或达到最大递归深度。  
  
光源采样与光子功率计算：  
  
对于点光源，辐亮度为：  
  
$$L_e = \frac{\Phi}{4\pi}$$  
  
每个光子的功率为：  
  
$$\frac{\Phi}{N}$$  
  
其中 $\Phi$ 为光源总功率，$N$ 为发射光子总数。  
  
对于面光源，辐亮度为：  
  
$$L_e = \frac{\Phi}{A} \cdot \frac{\cos\theta}{\pi}$$  
  
其中 $A$ 为光源面积，$\theta$ 为立体角方向与法向量的夹角。  
  
### 阶段二：渲染  
  
从摄影机发射射线进行路径追踪。当射线与漫反射表面相交时，查询光子贴图中该点附近的光子，通过密度估计计算该点的焦散光照贡献。  
  
密度估计使用最近邻搜索，定位相交点周围指定半径内的光子，累加其功率并除以搜索区域面积，得到该点的辐射照度。  
  
### 时间复杂度  
  
- 光子发射：$O(N)$，$N$ 为光子数量  
- 光子存储与查询：使用 kd-tree 或 BVH 加速结构，查询复杂度为 $O(\log M)$，$M$ 为存储的光子总数  
- 空间复杂度：$O(M)$，存储所有光子数据  
  
## 参考实现示例  
  
以下为光子映射核心流程的伪代码实现：  
  
```python  
# 光子数据结构  
class Photon:  
    position: Vector3  
    direction: Vector3  
    power: Vector3  # RGB功率  
  
# 阶段一：创建光子贴图  
def build_photon_map(scene, light, num_photons, max_depth):  
    photon_map = []  
    for _ in range(num_photons):  
        # 从光源采样光子初始位置、方向和功率  
        pos, dir, power = sample_light_source(light)  
        trace_photon(scene, pos, dir, power, photon_map, max_depth, 0)  
    build_kdtree(photon_map)  # 构建加速结构  
    return photon_map  
  
def trace_photon(scene, pos, dir, power, photon_map, max_depth, depth):  
    if depth >= max_depth or power < threshold:  
        return  
    hit = scene.intersect(pos, dir)  
    if not hit:  
        return  
    # 在漫反射表面记录光子  
    if hit.material.is_diffuse():  
        photon_map.append(Photon(hit.position, dir, power))  
    # 计算反射/折射方向并继续追踪  
    new_dir, new_power = bsdf_sample(hit.material, dir, hit.normal)  
    trace_photon(scene, hit.position, new_dir, new_power,   
                 photon_map, max_depth, depth + 1)  
```  
  
```python  
# 阶段二：渲染时查询光子贴图  
def render_pixel(scene, photon_map, ray, num_photons_search):  
    hit = scene.intersect(ray)  
    if not hit:  
        return background_color  
    if hit.material.is_diffuse():  
        # 查询最近的光子  
        photons = photon_map.find_nearest(hit.position, num_photons_search)  
        # 密度估计计算焦散贡献  
        caustic_contribution = Vector3(0, 0, 0)  
        radius = photons[-1].distance  # 最远光子距离  
        for p in photons:  
            caustic_contribution += p.power  
        caustic_contribution /= (PI * radius * radius)  
        return caustic_contribution  
    # 递归追踪反射/折射  
    return trace_reflection_refraction(scene, hit)  
```  
  
## 应用场景  
  
1. **水面渲染**：光线穿过动态水面折射后在池底或水下物体表面形成波纹状焦散图案。  
  
2. **透明材质渲染**：玻璃、宝石、水晶等物体的焦散效果是真实感渲染的关键组成部分。  
  
3. **光学系统仿真**：透镜、棱镜等光学元件的光路分析与焦散图案模拟。  
  
## 常见误区  
  
1. **焦散是直接照明效果**：焦散属于间接照明（Indirect Illumination）范畴，而非直接照明。光线需经过镜面表面的反射或折射后才到达漫反射表面。  
  
2. **所有渲染器默认支持焦散**：焦散计算需要显式启用光子追踪功能，并配置光子数量、搜索半径等参数。标准路径追踪器默认不包含焦散计算。  
  
## 性能权衡  
  
光子映射的优势在于能高效处理标准路径追踪难以收敛的焦散路径。其主要代价包括：  
  
- 光子数量增加时，内存占用和预处理时间线性增长  
- 存储在不可见区域的光子造成计算资源浪费  
- 光子搜索半径与光子数量的平衡影响渲染质量与噪声水平
