## 概念解释  
  
层次贝叶斯模型为参数引入先验分布，且先验分布的超参数服从更高层次的先验，形成多级结构。通过联合后验推断，实现组间信息共享。  
  
设观测数据 $y_{ij}$ 来自组 $i$，组参数 $\theta_i$ 服从共同先验 $p(\theta_i | \phi)$，超参数 $\phi$ 服从超先验 $p(\phi)$。联合后验分布为：  
  
$$p(\theta, \phi | y) \propto p(y|\theta) p(\theta|\phi) p(\phi)$$  
  
关键机制为部分池化：组间差异由超参数 $\phi$ 控制，平衡独立估计（无池化）与完全池化。推断时需边缘化超参数或联合采样。  
  
## 参考实现示例  
  
使用 Python 与 PyMC3 实现正态-正态层次模型：多组观测数据，每组均值不同但共享超先验。  
  
```python  
import pymc3 as pm  
import numpy as np  
  
# 模拟数据：5组，每组10个观测  
np.random.seed(42)  
groups = 5  
n_per_group = 10  
true_means = np.random.normal(0, 1, groups)  
data = [np.random.normal(mu, 1, n_per_group) for mu in true_means]  
  
with pm.Model() as hierarchical_model:  
    # 超先验  
    mu_hyper = pm.Normal('mu_hyper', mu=0, sigma=10)  
    sigma_hyper = pm.HalfNormal('sigma_hyper', sigma=10)  
    
    # 组参数先验  
    theta = pm.Normal('theta', mu=mu_hyper, sigma=sigma_hyper, shape=groups)  
    
    # 似然  
    y = pm.Normal('y', mu=theta, sigma=1, observed=data)  
    
    # MCMC采样  
    trace = pm.sample(1000, return_inferencedata=False)  
```  
  
典型推断算法步骤（MCMC）：  
1. 初始化参数 $\theta^{(0)}, \phi^{(0)}$。  
2. 对于每次迭代 $t = 1..T$：  
   - 对每个组参数 $\theta_i$ 从条件后验 $p(\theta_i | \theta_{-i}, \phi, y)$ 采样。  
   - 对超参数 $\phi$ 从条件后验 $p(\phi | \theta, y)$ 采样。  
3. 收敛诊断后获得后验样本。  
  
时间复杂度：$O(T \cdot N \cdot D)$，其中 $T$ 为迭代次数，$N$ 为总数据量，$D$ 为参数维度。空间复杂度：$O(T \cdot D)$ 存储后验样本。  
  
## 应用场景  
  
1. **个性化推荐**：用户分组（如地域），共享全局偏好超参数，同时估计个体参数，解决冷启动问题。  
2. **医学 Meta 分析**：整合多个临床试验数据，估计整体效应量及各研究特异性效应，处理异质性。  
3. **小样本学习**：每组仅少量观测时，通过组间信息共享提升参数估计稳定性。  
  
## 常见误区  
  
- **误区**：层次贝叶斯模型必须使用 MCMC，且计算极慢。  
  **纠正**：对于共轭层次模型（如正态-正态），Gibbs 采样可高效实现；变分推断（如 ADVI）提供近似后验，适用于大规模数据。  
- **误区**：将超参数 $\phi$ 视为固定值，用经验贝叶斯点估计替代后验积分。  
  **纠正**：忽略超参数不确定性会导致后验方差被低估，降低区间估计的覆盖率。应通过贝叶斯方法边缘化 $\phi$。
