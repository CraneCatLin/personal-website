# 提示词模板（专业简明版，含 LaTeX 格式要求）  
  
请为我生成一份关于「[概念名称]」的 Markdown 格式学习笔记，要求如下：  
  
1. **语言风格**：直接、专业、准确。**严禁使用类比、比喻、拟人或任何生活化类比**（例如不要写“就像…”、“好比是…”、“可以想象成…”）。可以适当简化描述，但必须保持术语的正确性。  
2. **结构简单**：最多使用二级标题（##）和三级标题（###）。每个小节的分点不超过 5 个。整体层次不超过两级。  
3. **内容必须包含以下部分**：  
   - **概念解释**：用一段话或少量要点说明该概念的定义、核心机制或设计思想。不要讲故事或场景引入。  
   - **参考实现示例**：提供伪代码或主流语言（如 Python/Java/C++）的真实代码片段，展示典型操作。  
   - **应用场景**：列出 2~3 个具体的技术场景，说明该概念解决什么问题，不展开过多解释。  
4. **附加内容（可选）**：1~2 个常见误区的纠正，或者一个紧密相关的专业扩展（如性能权衡、变体等）。不要求必须包含。  
5. **深度要求**：内容应覆盖该概念的关键原理、必要的数据结构或算法步骤，以及典型的时间/空间复杂度（如适用），避免停留在定义层面。  
6. **LaTeX 格式**：笔记中出现的所有数学公式、符号或表达式，**必须使用 `$$...$$` 包裹**，禁止使用 `\(...\)` 或 `\[...\]`。若公式位于行内，则统一使用 `$...$`。  
7. **输出格式**：纯 Markdown，标题为 `# [概念名称]`。代码块必须标注语言。不要使用表情符号或装饰性符号。  
  
请严格按照上述要求生成笔记。
