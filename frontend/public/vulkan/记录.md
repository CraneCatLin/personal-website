## 编译器  
  
虽然推荐用VS，但是个人更喜欢vscode和它的一些插件，就折腾了一下配置导入msvc 的终端  
  
项目工作区.vscode/settings.json内写入  
```  
{  
    "terminal.integrated.profiles.windows": {  
        "MSVC Dev Prompt": {  
            "path": "cmd.exe",  
            "args": [  
                "/k",  
                "[visual studio path]2022\\Community\\VC\\Auxiliary\\Build\\vcvars64.bat"  
            ],  
            "icon": "terminal-cmd"  
        }  
    },  
    "terminal.integrated.defaultProfile.windows": "MSVC Dev Prompt"  
}  
```  
替换一下路径，然后该项目默认打开的终端就默认msvc环境了  
  
不用vs也就不需要sln了，所以用ninja  
相应教程中配置环境cmake改为  
```  
cmake -B build -S . -G Ninja -DCMAKE_TOOLCHAIN_FILE=[vcpkg path]\scripts\buildsystems\vcpkg.cmake  
```
