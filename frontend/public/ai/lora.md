# 概述  
为了解决大模型参数庞大不便于微调的问题  
  
在transformer中应用于多头注意力  
  
小矩阵相乘获得低秩大矩阵，并加在原有的大矩阵上  
  
生效的机制：任务适配只需要调整少量特征方向，且这些方向本来就存在于预训练模型中，只是被低秩更新显著放大  
# 推导  
#### 表达式  
对于一个线性层，其更新方式的变化  
  
$$  
h=W_0*x +\Delta W*x \to h=W_0*x + B*A*x  
$$  
$W_0$在训练时冻结，只需要更改A和B  
  
#### 秩：  
- $W_0 \in \mathbb{R}^{d \times k}$：冻结的预训练权重  
- $A \in \mathbb{R}^{r \times k}$，$B \in \mathbb{R}^{d \times r}$  
- 秩 $r \ll \min(d, k)$，通常取 4、8、16 等小值  
  
#### 初始化：  
- $A$**：随机高斯初始化。  
- $B$**：**零初始化**，保证训练开始时 $B A = 0$，模型输出与原始预训练模型完全一致。  
#### 缩放因子  
- 实际计算时将$\Delta W x$乘以 $\frac{\alpha}{r}$（$\alpha$ 为常数）  
- 使用 Adam 优化时，调 $\alpha$等价于调学习率，通常 $\alpha$ 固定为尝试的第一个 r 值  
- 作用：减少超参数对 r 变化的敏感度  
#### 与全微调的关系  
- 若将 LoRA 应用于所有权重矩阵并训练所有偏置，当  r = 预训练权重秩 时，LoRA 可恢复全微调的表达能力  
- 增加可训练参数时，LoRA → 全微调；Adapter 方法 → MLP；Prefix 方法 → 受限于序列长度  
#### 无额外推理延迟  
部署时可提前计算并存储 W = W_0 + BA，直接用于推理  
切换任务时只需减去当前 BA，加上新的B'A'，无需重新加载整个模型，与全微调模型相比不引入任何额外延迟  
  
## transformer应用  
  
  
#### 概述  
多头注意力应用lora可以仅替换AB实现多组$W_q ,W_k ,W_v$矩阵  
多任务同理  
#### 适用模块  
- 重点关注**自注意力模块**的四个权重矩阵：$W_q, W_k, W_v, W_o$  
- 也适用于 MLP 模块的权重矩阵  
- 论文中为简洁高效，默认**冻结 MLP 模块**，仅微调注意力权重  
#### 实际收益  
| 收益项    | 说明                                                                |  
| ------ | ----------------------------------------------------------------- |  
| 显存减少   | 冻结参数无需存储 Adam 优化器状态（动量、方差等），VRAM 可减少 2/3。GPT-3 175B：1.2TB → 350GB |  
| 存储减少   | r=4 ，仅微调$W_q, W_v$ 时，检查点从 350GB → 35MB                            |  
| 训练加速   | GPT-3 175B 上训练速度提升约 **25%**（大部分参数无需计算梯度）                          |  
| 快速任务切换 | 部署时只需交换 LoRA 权重，无需重新加载整个模型                                        |  
#### 局限性  
- 若为消除推理延迟而将 BA 合并到 W 中，则无法在同一个 batch 中混合不同任务的输入（因为不同任务需要不同的 A, B）  
- 若延迟不敏感，可以不合并，动态选择 LoRA 模块
