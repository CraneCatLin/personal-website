# 循环神经网络（RNN）概述  
循环神经网络是一类用于处理序列数据的人工神经网络。与传统前馈网络不同，RNN 在隐藏层节点之间引入循环连接，使网络能够保持对历史信息的“记忆”，从而捕捉序列中的时间依赖性。  
循环神经网络是一类专门处理**序列数据**（如文本、语音、股价）的神经网络。它的核心能力是**拥有记忆**——处理当前信息时，会参考之前看到的内容。  
  
# 核心思想  
RNN 在每个时间步接收输入，并结合上一个时间步的隐藏状态产生当前输出和新的隐藏状态。这种参数共享机制使得同一个模型可以应用于任意长度的序列，并且学到的模式可以泛化到序列中不同位置。  
  
# 基本结构  
- **输入层**：接收序列中每个时间步的输入 $x_t$。  
- **隐藏层**：维持一个隐藏状态 $h_t$，它既取决于当前输入 $x_t$，也取决于上一时刻的隐藏状态 $h_{t-1}$。  
- **输出层**：基于当前隐藏状态生成输出 $y_t$（可能只在某些时间步需要输出）。  
- **权重参数**：三个权重矩阵 $W_{xh}$（输入到隐藏）、$W_{hh}$（隐藏到隐藏）、$W_{hy}$（隐藏到输出），在整个时间轴上共享。  
  
# 前向传播公式  
假设激活函数为 $\tanh$，输出层激活视任务而定：  
- 隐藏状态更新：$h_t = \tanh(W_{xh} x_t + W_{hh} h_{t-1} + b_h)$  
- 输出：$y_t = W_{hy} h_t + b_y$（回归）或经过 softmax（分类）。  
对于长度为 $T$ 的序列，上述计算从 $t=1$ 到 $t=T$ 逐步展开，形成一个沿时间展开的计算图。  
  
# 随时间反向传播（BPTT）  
训练 RNN 通常使用随时间反向传播算法。本质是将展开后的网络当作一个极深的前馈网络（深度为时间步数），应用链式法则计算损失对各参数的梯度。  
- 损失 $L$ 通常定义为所有时间步输出与目标之间损失的总和（或平均值）。  
- 隐藏状态梯度需要从 $t=T$ 向前递推到 $t=1$：$\frac{\partial L}{\partial h_t}$ 依赖于 $\frac{\partial L}{\partial h_{t+1}}$。  
- 参数梯度是所有时间步梯度之和：  
  
  $$  
  \frac{\partial L}{\partial W_{hh}} = \sum_{t=1}^T \frac{\partial L}{\partial h_t} \cdot \frac{\partial h_t}{\partial W_{hh}}  
  $$  
  实际中常用截断 BPTT，只反向传播固定步数以减少计算和缓解梯度问题。  
  
# 梯度消失与梯度爆炸  
BPTT 中反复乘以相同的权重矩阵 $W_{hh}$，导致：  
- **梯度爆炸**：若 $W_{hh}$ 的最大特征值大于 1，梯度呈指数增长。可用梯度裁剪缓解。  
- **梯度消失**：若最大特征值小于 1，梯度呈指数衰减，使 RNN 难以学习长距离依赖。激活函数（如 $\tanh$）的饱和区会加剧这一问题。  
这两个问题严重限制了朴素 RNN 对长序列的建模能力。  
  
# 长短期记忆网络（LSTM）  
LSTM 通过引入门控机制和细胞状态来缓解梯度消失问题。核心是“细胞状态” $C_t$，它像传送带一样贯穿时间，只经过线性的少量交互，便于梯度流动。  
- **遗忘门**：$f_t = \sigma(W_f [h_{t-1}, x_t] + b_f)$ 决定丢弃哪些旧信息。  
- **输入门**：$i_t = \sigma(W_i [h_{t-1}, x_t] + b_i)$，候选值 $\tilde{C}_t = \tanh(W_C [h_{t-1}, x_t] + b_C)$。  
- **细胞状态更新**：$C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$。  
- **输出门**：$o_t = \sigma(W_o [h_{t-1}, x_t] + b_o)$，隐藏状态 $h_t = o_t \odot \tanh(C_t)$。  
其中 $\sigma$ 为 sigmoid 函数，$\odot$ 表示逐元素乘法。门控使 LSTM 能选择性地记住或遗忘信息，有效捕获长距离依赖。  
  
# 门控循环单元（GRU）  
GRU 是 LSTM 的一种简化变体，将遗忘门和输入门合并为更新门，并合并细胞状态与隐藏状态。  
- **重置门**：$r_t = \sigma(W_r [h_{t-1}, x_t] + b_r)$ 控制忽略多少过去信息。  
- **更新门**：$z_t = \sigma(W_z [h_{t-1}, x_t] + b_z)$ 控制保留多少旧状态与引入多少新状态。  
- **候选隐藏状态**：$\tilde{h}_t = \tanh(W_h [r_t \odot h_{t-1}, x_t] + b_h)$。  
- **最终隐藏状态**：$h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t$。  
GRU 参数更少，训练更快，在很多任务上与 LSTM 性能相当。  
  
# 其他常见变体  
- **双向 RNN**：由两个独立的 RNN 组成，一个正向处理序列，一个反向处理序列，每个时间步的输出由两个方向的隐藏状态拼接而成。可以捕捉当前时刻的上下文信息，适用于序列标注、机器翻译等非因果任务。  
- **深度 RNN**：将多层 RNN 堆叠，低层输出作为高层输入。可以学习更抽象的时间特征，但同样面临梯度问题，通常结合 LSTM/GRU 使用。  
- **递归神经网络（Recursive NN）**：处理树状结构而非序列，不同节点共享权重，适用于句法分析等。  
  
# 应用场景  
- **自然语言处理**：语言建模、文本生成、机器翻译、命名实体识别、情感分析。  
- **语音处理**：语音识别、语音合成。  
- **时间序列预测**：股票价格、天气预测、传感器数据分析。  
- **视频分析**：视频描述生成、动作识别。  
- **生物信息学**：DNA 序列分析、蛋白质结构预测。  
  
# 优缺点总结  
**优点**：  
- 能够建模任意长度的序列依赖（理论上）。  
- 参数在时间上共享，模型大小不随序列长度增长。  
- 可接受可变长度输入和输出，适用于多种序列转换模式。  
  
**缺点**：  
- 朴素 RNN 难以训练，存在梯度消失/爆炸问题。  
- 计算不能完全并行化（时间步需顺序计算），训练速度慢。  
- 即使 LSTM/GRU，对于极长序列（数百到上千步）仍有困难。  
- 对超长距离依赖的建模能力弱于后来的 Transformer 等基于注意力机制的模型。  
  
# 训练技巧  
- **梯度裁剪**：将梯度范数限制在一定阈值内，防止梯度爆炸。  
- **截断 BPTT**：仅展开固定长度的时间步进行反向传播，平衡效率与长程依赖。  
- **Teacher Forcing**：训练时将真实输出（而非模型生成的输出）作为下一时间步的输入，加速收敛，但可能引入训练与推理的不一致。  
- **正则化**：对权重矩阵应用 dropout（尤其非时间连接部分），或使用 zoneout、层归一化等稳定训练。  
  
# 与 Transformer 的简要对比  
RNN 按顺序处理输入，天然具有时间归纳偏置，但并行化困难；Transformer 完全基于自注意力，可并行处理整个序列，长距离依赖建模更强，现已成为许多序列任务的首选。但 RNN 及其变体在在线序列建模、资源受限环境下仍有一席之地。
