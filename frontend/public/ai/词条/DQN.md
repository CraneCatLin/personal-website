## 1. 传统 Q-learning 的局限  
- 使用表格 $Q(s,a)$ 存储状态-动作值  
- 状态空间过大（连续、高维）时不可行，泛化能力差  
  
## 2. DQN 核心思想  
- 用**深度神经网络** $Q(s,a;\theta)$ 近似 $Q^*(s,a)$  
- 输入：原始状态（如图像像素）  
- 输出：每个动作的 Q 值  
- 实现端到端学习，自动提取特征  
  
## 3. 两大关键技术（解决训练不稳定）  
  
### 3.1 经验回放 (Experience Replay)  
- 将交互经验 $(s,a,r,s')$ 存入**回放缓存** $D$  
- 训练时随机采样 mini-batch  
- 作用：打破样本相关性，提高样本效率  
  
### 3.2 目标网络 (Target Network)  
- 维护两个网络：  
  - 当前网络 $\theta$：用于选择动作、计算当前 Q 值  
  - 目标网络 $\theta^-$：用于计算目标 Q 值中的 $\max_{a'} Q(s',a';\theta^-)$  
- 每 $C$ 步将 $\theta$ 复制给 $\theta^-$（硬更新）  
- 作用：固定目标，减少震荡  
  
## 4. 算法流程  
  
```  
初始化当前网络 Q(s,a;θ)，目标网络 Q'(s,a;θ⁻)=Q(s,a;θ)  
初始化回放缓存 D  
  
for 每个回合:  
    初始化状态 s  
    for 每一步:  
        # ε-贪心选择动作  
        以概率 ε 随机选 a，否则 a = argmax Q(s,a;θ)  
        执行 a，得奖励 r 和下一状态 s'  
        存储 (s,a,r,s') 到 D  
        
        # 从 D 采样 mini-batch  
        对每个样本 (s,a,r,s') 计算目标 Q 值:  
            y = r                     (若 s' 终止)  
            y = r + γ max_a' Q'(s',a';θ⁻) (否则)  
        
        # 更新当前网络  
        损失 L = (y - Q(s,a;θ))²  
        梯度下降更新 θ  
        
        # 定期同步目标网络  
        if step % C == 0: θ⁻ = θ  
```  
  
## 5. 损失函数  
  
$$L(\theta) = \mathbb{E}_{(s,a,r,s')\sim D} \left[ \left( r + \gamma \max_{a'} Q(s',a';\theta^-) - Q(s,a;\theta) \right)^2 \right]$$  
  
## 6. 主要成就  
- Atari 49 款游戏中 29 款超越人类专业玩家  
- 首次证明深度学习+强化学习的可行性  
- 开启深度强化学习时代  
  
## 7. 局限与改进  
  
| 局限 | 改进方法 |  
|------|----------|  
| Q 值过估计 | Double DQN |  
| 采样效率低 | Prioritized Experience Replay |  
| 动作空间连续 | DDPG, TD3, SAC |  
| 所有状态同权重 | Dueling DQN（拆分 $V(s)$ 与 $A(s,a)$） |  
  
## 8. 总结  
**DQN = 深度神经网络 + Q-learning + 经验回放 + 目标网络**
