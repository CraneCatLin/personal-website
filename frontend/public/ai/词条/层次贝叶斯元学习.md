\* 层次即分层  
  
## 概念解释  
  
层次贝叶斯元学习是一类通过层次贝叶斯模型对任务分布进行建模，从多个相关任务中提取先验知识，并快速适应新任务的元学习框架。其核心机制包含两层不确定性：顶层描述任务间参数的分布（超先验），底层描述每个任务特定参数的条件分布。给定任务集 $\{\mathcal{T}_1, \dots, \mathcal{T}_T\}$，每个任务 $\mathcal{T}_t$ 的数据 $\mathcal{D}_t$ 生成自似然 $p(\mathcal{D}_t \mid \theta_t)$，其中任务参数 $\theta_t$ 从共享超参数 $\phi$ 的先验 $p(\theta_t \mid \phi)$ 中采样。元学习目标为推断超参数 $\phi$ 的后验分布，并基于此对新任务进行预测。  
  
关键数学形式：  
- 联合分布：$$p(\{\theta_t\}, \phi, \{\mathcal{D}_t\}) = p(\phi) \prod_{t=1}^T \left[ p(\theta_t \mid \phi) p(\mathcal{D}_t \mid \theta_t) \right]$$  
- 新任务 $\mathcal{T}_{new}$ 的预测后验：$$p(y_{new} \mid x_{new}, \mathcal{D}_{1:T}) = \int p(y_{new} \mid x_{new}, \theta) p(\theta \mid \mathcal{D}_{new}) p(\phi \mid \mathcal{D}_{1:T}) d\theta d\phi$$ 其中 $\mathcal{D}_{new}$ 为新任务少量数据。  
  
## 参考实现示例  
  
以下为使用概率编程语言（如 PyMC）实现层次贝叶斯元学习的伪代码框架，模拟从多个回归任务中学习共享先验。  
  
```python  
import pymc as pm  
import numpy as np  
  
# 模拟多个任务的数据  
T = 10          # 任务数  
n_per_task = 20 # 每个任务样本数  
  
# 真实超参数：权重 w 的均值和方差  
true_phi_mu = 1.5  
true_phi_sigma = 0.5  
  
tasks_data = []  
for t in range(T):  
    w_true = np.random.normal(true_phi_mu, true_phi_sigma)  
    x = np.random.randn(n_per_task)  
    y = w_true * x + 0.1 * np.random.randn(n_per_task)  
    tasks_data.append((x, y))  
  
# 层次贝叶斯模型定义  
with pm.Model() as hierarchical_model:  
    # 超先验  
    phi_mu = pm.Normal('phi_mu', mu=0, sigma=2)  
    phi_sigma = pm.HalfNormal('phi_sigma', sigma=1)  
    
    # 任务级参数  
    w = pm.Normal('w', mu=phi_mu, sigma=phi_sigma, shape=T)  
    
    # 似然  
    for t in range(T):  
        x_t, y_t = tasks_data[t]  
        mu_t = w[t] * x_t  
        pm.Normal(f'likelihood_{t}', mu=mu_t, sigma=0.1, observed=y_t)  
  
# 推断超参数后验  
with hierarchical_model:  
    trace = pm.sample(1000, tune=500, chains=2)  
  
# 新任务适应：使用后验超参数作为先验，在新数据上更新  
new_x = np.array([0.5, 1.2, -0.3])  
new_y = np.array([0.8, 1.9, -0.4])  
with pm.Model() as adapt_model:  
    # 从元学习得到的超参数后验近似（例如使用 trace 中的均值）  
    prior_mu = trace.posterior['phi_mu'].mean().item()  
    prior_sigma = trace.posterior['phi_sigma'].mean().item()  
    w_new = pm.Normal('w_new', mu=prior_mu, sigma=prior_sigma)  
    mu_new = w_new * new_x  
    pm.Normal('likelihood', mu=mu_new, sigma=0.1, observed=new_y)  
    adapt_trace = pm.sample(500)  
```  
  
## 应用场景  
  
- **少样本图像分类**：从多个已知类别（任务）学习特征表示的先验分布，在新类别仅给少量标注样本时快速更新分类器参数。  
- **个性化推荐系统**：用户群体各用户（任务）的偏好参数共享超先验，新用户通过少量交互数据即可推断个性化参数。  
- **元强化学习**：在多个马尔可夫决策过程任务上学习奖励函数或转移模型的先验，新任务中利用少量轨迹快速适应策略。  
  
## 常见误区  
  
- **将任务级参数 $\theta_t$ 视为独立并忽略超参数不确定性**：实际应用中常使用点估计（如最大化边际似然）近似超参数，但完全贝叶斯处理需积分 $\phi$ 的后验。忽略超参数后验方差会导致对新任务的适应过于自信（欠拟合不确定性）。  
- **混淆层次贝叶斯与普通贝叶斯神经网络**：前者显式建模任务分布层次，后者通常仅对单一模型的权重设先验。层次贝叶斯元学习中各任务拥有独立参数，共享超先验，而非单一模型参数的后验。  
  
## 扩展：与 MAML 的关系  
  
模型无关元学习（MAML）可视为层次贝叶斯元学习的近似：MAML 寻找初始化参数 $\phi$，使得对新任务执行一步梯度更新后得到 $\theta_t$。其目标等价于在均场变分推断下，假设任务后验为狄拉克 $\delta$ 分布，且超参数 $\phi$ 的点估计最大化边际似然。相比之下，层次贝叶斯方法保留超参数后验分布，能更精确量化元学习中的不确定性。
